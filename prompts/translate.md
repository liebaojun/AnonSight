# 任务：论文阅读时的即时翻译

用户正在读英文论文，选中了一个词或短语。产品逻辑**定死了顺序**：

1. **先给整句译文**——多义词必须靠上下文才能定，脱离句子的词义是猜的
2. **再给"这个词在这句话里"的意思**——不是词典义项罗列，是**语境义**

## 输出（只输出 JSON，不要解释）

```json
{
  "sentenceZh": "整句的中文译文（通顺、学术语气，不要逐字硬译）",
  "termZh": "选中部分在**这个语境下**的中文意思",
  "kind": "术语|搭配|动词|逻辑|句式|单词",
  "warn": "⚠ 可选。这个词容易理解错时，写一句『不是××』式的提醒；没有就留空字符串",
  "note": "可选。一句话讲清用法/搭配/近义词；没有就留空字符串"
}
```

## 铁律

- 译文里**只保留这几类英文**，其余一律翻成中文：
  · 基因/蛋白/受体名（Csk、Lck、CD3ζ、TCR、CAR-T、ITAM、p85）
  · 文献里当专名用的缩写（ACD、CARIS、MTOC、LIPSTIC）
  · 通用学术词**必须翻**：`signaling` → 信号传导、`chimeric antigen receptor` → 嵌合抗原受体、
    `antigen engagement` → 抗原接合、`persistence` → 持久性
  ⚠ 验收实测过：把 `signaling`、`chimeric antigen receptor` 原样留英文，读起来是夹生的
    （"工程化受体 signaling 如何调控 chimeric antigen receptor (CAR)-T 细胞"）。
    专名保留是为了**能对上原文**，不是为了省事。
- `termZh` 要**贴合本句语境**。例：`charge` 在免疫学论文里常指"电荷"而不是"收费"、
  "指控"；`discriminate` 是"区分/精确辨别"而不是"歧视"
- `warn` 只在**真的容易理解错**时才写，别每条都写（写多了就成了噪音）
- 不要输出词典式的多项罗列，只给**这一句里的那一个意思**
