    这是什么？

    AnonSight 是一个把论文的思想结构画出来的精读工具： 左边摘录、中间原文、右边是跟着章节走的图。 读一篇陌生领域的论文时，不用先在脑子里把整篇的骨架搭好。

    把 PDF 拖到页面上就能入库。平台会自动切节，逐节抽出概念与它们之间的关系， 给全文打上表达标注，并把译文准备好。

    怎么用

    • 点任意气泡 → 它变成中心，周围重新铺开
    • 点任意箭头 → 看这条关系的原文依据（左栏会跳到支撑它的那句话）
    • 滚轮缩放图 · 拖动平移 · 拖动气泡可手工摆位 · 右上角可切主题
    • PDF 上的彩色高亮悬停 → 出中文释义与用法提示
    • 划词 → 左栏给整句译文 + 这个词在这个语境下的意思
    • 选中文字可高亮成自己的标记 · 顶栏「清除」再点一下就能去掉
    • 顶栏「论文库」切论文 · 「一键分析」重新跑一遍全自动流水线

    图是怎么来的

    • 每一张图都是 AI 读完全文之后逐节抽出来的，不是套模板
    • 每一个方块、每一条箭头都必须能点回原文那句 —— 回不去的关系宁可不画
    • 所以模型产出的每一版都要过一道硬校验（引文必须在原文里原样命中）， 不过就带着错误重试
    • 你看到的图，是通过校验才画得出来的

    关于 .ano 文件

    平台的存库格式是 .ano。它本身就是一份标准 PDF —— 分析成果（思想图、标注、译文）作为附件封在同一个文件里， 所以双击它、发给别人、或者用别的 PDF 阅读器打开，都不会坏。

    设置 · AI 接口

    接一个模型（可选）

    填 接口地址 + 模型名 + API Key 三样，「一键分析」和划词翻译就能用。 任何 OpenAI 兼容的服务都行 —— DeepSeek、Kimi、智谱 GLM、OpenAI、本地 Ollama…

    不填也能用 —— 平台照样能打开 .ano 文件、看章节切分、思想图和已有标注， 只是不能重新跑一遍分析、也不能实时翻译。

    Key 框空着 ≠ 没配 —— 已保存的 Key 不会回填显示（安全考虑），看上面的状态行才准。

    Key 只存在这台电脑上、只发给你填的那个地址，不会传到别处。
    选「自定义」时可以填任何兼容服务（含局域网/本机的模型服务，那种连 Key 都不用填）。

    请从 AnonSight 程序里打开

    浏览器不允许网页直接读取本机文件（安全限制）， 所以这个页面不能直接用浏览器打开。

    1. 关掉这个页面
    2. 用开始菜单或桌面上的 AnonSight 快捷方式启动
    3. 或者直接双击任意一个 .ano 文件

    这不是故障，是浏览器对 file:// 的协议限制。
